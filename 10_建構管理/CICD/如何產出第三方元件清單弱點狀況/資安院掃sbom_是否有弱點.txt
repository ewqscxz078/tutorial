0. window 安裝
	for 掃描出 sbom : syft
		指令安裝方式
			in powershell 終端機
				winget source update
				winget source reset --force // if winget source update fail

				winget search syft // check

				winget install Anchore.Syft

		zip 人工安裝方式
			1. 先到 https://github.com/anchore/syft/releases
				將 Assets 展開
					點擊 syft_*_windows_amd64.zip 下載

			2.解壓縮後取得：
				syft.exe

			3.Windows PATH 加入
				比如
					D:\no_sync_oneDrive\green_tools\other_tools\syft_1.46.0_windows_amd64
						// has syft.exe
			4.git bash
				syft version

2. 從 SBOM 檔案產生報告
	* 使用 Grype 掃描 SBOM 檔案 // 因為跟 syft 同一家公司
		
	* 使用 OSV-Scanner 掃描 SBOM 檔案 // 政府推薦
		語法
			osv-scanner scan -L ./path/to/sbom/file --format=table --output-file=report.txt
			
		範例 of table(default)
			單一 repo dir
				osv-scanner scan -L /d/no_sync_oneDrive/MYDATA_CODE/sbom/20260702/mydata-backend-113_syft.spdx.json --format=table --output-file=/d/no_sync_oneDrive/MYDATA_CODE/sbom/20260702/report_cvs.txt

			全部 repo dir
				// table
				osv-scanner scan -L /d/no_sync_oneDrive/MYDATA_CODE/sbom/20260702/all_repo_syft.spdx.json --format=table --output-file=/d/no_sync_oneDrive/MYDATA_CODE/sbom/20260702/report_all_repo_cvs.txt

				// html
				osv-scanner scan -L /d/no_sync_oneDrive/MYDATA_CODE/sbom/20260702/all_repo_syft.spdx.json --format=html --output-file=/d/no_sync_oneDrive/MYDATA_CODE/sbom/20260702/report_all_repo_cvs.html


1.使用 syft(目前最新1.46.0) 掃描專案(分支:env-production) 產生 sbom

2.使用 OSV-Scanner(目前最新v2.4.0) 針對 sbom 生成有弱點結果

初步了解工具部分限制
	專案內自行
		* 放入 local jar 引用，掃描工具掃不出來
		* 放入 第三方js(非 webjars 模式) 然後於 html/xhtml 裡引用，掃描工具辨識不太出來
	    * 於 html/xhtml 裡引用 第三方外部 CDN url js，SBOM 工具通常不會把 CDN 引用納入，所以就沒有報告

	該報告會分比較細，會說第三方套件版本於哪個版本修了那些 CVE，
		* 一般沒意外是直接升到對應的最新，但也有可能沒有辦法升版對應到最新，比如彼此之間的依賴傳遞狀況
		* 比較糟糕的是有弱點但沒有版本可修正要另外找對應替代方案
