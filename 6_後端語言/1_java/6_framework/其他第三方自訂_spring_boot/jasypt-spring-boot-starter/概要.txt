使用 jasypt 加密指定的字串
	方法一：使用 Maven Plugin
		但可能會因為 application.yml 有 import config 但找不到問題
			例如如下問題
				Description:

				Config data resource 'class path resource [config/swagger.yml]' via location 'classpath:config/swagger.yml' does not exist

				Action:

				Check that the value 'classpath:config/swagger.yml' at URL [file:src/main/resources/application.yml] - 84:7 is correct, or prefix it with 'optional:'

		加入 Plugin：
			<profiles>
			  <!-- 執行方式 ./mvnw -profile=jasyptGen jasypt:encrypt-value -Djasypt.encryptor.password=<my-secret-key> -Djasypt.plugin.value="<Password>" -->
			  <profile>
				<id>jasyptGen</id>
				<build>
				  <resources>
					<resource>
					  <directory>${project.basedir}/src/main/resources</directory>
					  <filtering>false</filtering>
					  <includes>
						<include>application.yml</include>
						<include>application-*.yml</include>
						<include>config/**/*.yml</include>
					  </includes>
					</resource>
				  </resources>
				  <plugins>
					<plugin>
					  <groupId>com.github.ulisesbocchio</groupId>
					  <artifactId>jasypt-maven-plugin</artifactId>
					  <version>3.0.5</version>
					</plugin>
				  </plugins>
				</build>
			  </profile>
			</profiles>
				// 注意：
					jasypt-spring-boot-starter 是 4.0.4，
					Maven Plugin 最新仍是 3.0.5，這是正常的。

		例如你的 DB 密碼是
			MyDbPassword123!
		你的主密碼（Master Password）
			my-secret-key

		格式
			mvn jasypt:encrypt-value \
			-Djasypt.encryptor.password=<MasterPassword> \
			-Djasypt.plugin.value="<DB Password>"

			./mvnw jasypt:encrypt-value \
			-PjasyptGen \
			-Djasypt.encryptor.password=<MasterPassword> \
			-Djasypt.plugin.value="<DB Password>" \
			-Dspring.profiles.active=local

			./mvnw jasypt:encrypt-value \
			--activate-profiles jasyptGen \
			-Djasypt.encryptor.password=<MasterPassword> \
			-Djasypt.plugin.value="<DB Password>" \
            -Dspring.profiles.active=local

		範例執行
			mvn jasypt:encrypt-value \
			  -Djasypt.encryptor.password=my-secret-key \
			  -Djasypt.plugin.value="MyDbPassword123!"

			./mvnw -Pdev clean package

		會得到類似
			ENC(FwY5S2M2D5Q6M2....)

		放到 application.yml
			spring:
			  datasource:
				password: ENC(FwY5S2M2D5Q6M2....)

		啟動時再提供
			JASYPT_ENCRYPTOR_PASSWORD=my-secret-key

	方法二：寫一支 Java 小工具（也很常見）

		JasyptEncryptorConfigurationProperties
		@Slf4j
		@ActiveProfiles("test")
		@SpringBootTest
		public class JasyptGeneratorTest {

			  @Test
			  void testGen() {
					StandardPBEStringEncryptor encryptor = new StandardPBEStringEncryptor();
					SimpleStringPBEConfig config = new SimpleStringPBEConfig();

					// 1. Set your master private password/secret key
					config.setPassword("your_secret_master_key"); //

					// 2. Set the algorithm (Jasypt Starter 3.x+ defaults ref JasyptEncryptorConfigurationProperties)
					config.setAlgorithm("PBEWITHHMACSHA512ANDAES_256");
					config.setKeyObtentionIterations(1000);
					config.setPoolSize(1);
					config.setSaltGeneratorClassName("org.jasypt.salt.RandomSaltGenerator");
					config.setIvGeneratorClassName("org.jasypt.iv.RandomIvGenerator");
					encryptor.setConfig(config);

					// 3. Encrypt your plain-text secret
					String plainText = "my_password"; //
					String encryptedText = encryptor.encrypt(plainText);

					log.debug("Plain Text: {}", plainText);
					log.debug("Encrypted (Put inside ENC(...)): {}", encryptedText);
			  }
		}
		// 若要與 Starter 4.0.4 的預設一致，則需把演算法等參數也設一致，不然可能與 Spring Boot 啟動時的設定不同。
