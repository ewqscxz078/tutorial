Q1:
	ChatGPT 網頁版上方看到的「對話」與「工作（Work）」選項差異?

A1:
	對話偏「跟 AI 討論」，
	工作偏「把任務交給 AI 執行」。
	這是 2026 年新版 ChatGPT 很重要的區分。
	OpenAI 官方也是這樣定位：
		對話用於提問、搜尋、腦力激盪；
		工作則用於研究、分析，以及建立文件、試算表、簡報、報告或網站。

	| 面向          | 對話 Chat                              | 工作 Work                                      |
	| ------------- | -------------------------------------- | ---------------------------------------------- |
	| 核心概念      | **你問，我回答**                       | **你交代目標，我完成任務**                     |
	| 適合          | 問問題、討論、程式架構、除錯、快速研究 | 長時間研究、分析大量資料、產出完整成果         |
	| 執行方式      | 以一來一往對話為主                     | 可以自主進行多個步驟                           |
	| 檔案          | 可以讀取、分析                         | 更強調跨檔案處理與產出成品                     |
	| 網頁          | 可以搜尋網路資訊                       | 可以使用獨立的**雲端瀏覽器**實際操作支援的網站 |
	| 外掛/連接服務 | 可以使用                               | 更強調跨 App、Plugin、檔案完成工作流程         |
	| 背景執行      | 通常是當下處理                         | 可以在你離開後繼續執行                         |
	| 排程/監控     | 可另外設定任務                         | 本身就是 Work 的重要能力之一                   |


	使用 「對話」 可以跟 AI
		反覆討論、貼程式碼、修正架構。


	使用 「工作」 可以跟 AI
		讀檔案 → 搜尋資料 → 分析 → 交叉比對 → 建立文件/Excel → 檢查結果 → 交付成果
