單一repo 前後端專案再一起盤點模式
	第一階段：只盤點
		請先不要建立正式架構、開發與維運文件。

		請完整盤點 mydata-routine-jobs，建立：

		- docs/README.md
		- docs/inventory/repository-inventory.md
		- docs/inventory/app-core-inventory.md
		- docs/inventory/backend-web-inventory.md

		盤點必須涵蓋：

		- repository 根層建置與部署
		- app-core Spring Boot
		- backend-web Vue
		- 前後端 API 與部署整合
		- security
		- configuration
		- observability
		- tests
		- legacy 與風險

		所有發現分成 Confirmed、Needs verification、Unknown 與 Recommendation。
		每項重要結論列出程式碼或設定檔證據。
		不得輸出 secret。

		完成盤點後先停止，不要根據未確認項目生成正式文件。


第二階段：正式化文件
	請根據已確認的三份 inventory，以及目前 repository 程式碼，建立先前約定的完整 docs、README.md 與 AGENTS.md 結構。
