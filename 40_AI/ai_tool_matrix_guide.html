核心觀念

忘記產品名稱，記住「AI 的 4 大層級」

現今各大 AI 巨頭的產品線已不再是單純的「聊天機器人」，而是朝向「長任務 Agent」與「軟體工程自動化」發展。團隊不應強制限定統一的 AI 廠牌，而是應定義統一的 AI Role (角色協定)。

Level 1

Chat 對話/思考

問問題、討論架構、發想概念、腦力激盪。

代表：ChatGPT, Claude.ai, Gemini
Level 2

Work Agent 知識工作

長時間多步驟任務、分析 Repo、產出文件與 Task 清單。

代表：ChatGPT Work, Claude Cowork
Level 3

Coding Agent 本機實作

讀寫本機 Repo、擬定 Plan、修改程式碼、跑 Test。

代表：Codex, Claude Code, Copilot Agent Mode
Level 4

Background Agent 雲端背景

非同步運作、雲端 VM 背景執行任務、主動提交 PR。

代表：Jules, Copilot Cloud Agent

四大廠牌生態系拆解與特色分析

1. OpenAI 生態系

定位明確的三階段分工

  • Chat 提問、搜尋、架構發想與腦力激盪。
  • Work 多步驟研究、資料分析、產出文件（Docs/Tasks）、簡報與報告。
  • Codex 深度 Coding、Debug、Command 執行、Test 驗證與 Code Review。

2. Anthropic 生態系

以 "Chat → Code → Cowork" 為演進軸心

  • Claude.ai 邏輯對話與長文字分析（直覺對標 ChatGPT Chat）。
  • Claude Cowork 接手跨文件、跨工具的多步驟通用知識工作（General Knowledge Work）。
  • Claude Code 專精於 Software Engineering，理解 Repo、規劃並執行工具。

3. Google 生態系

工具較分散，但包含強大的雲端 Agent

  • Gemini CLI 可閱讀程式碼、操作檔案、執行 Command，並相容 GEMINI.md 指示檔。
  • Agent Mode 提供「建立多步驟執行計畫，失敗時自動修復」之能力。
  • Jules 非同步雲端 Agent： Clone GitHub Repo 至 Google Cloud VM，背景自主分析、修改程式碼、跑測試並產出 Diff 供 Review。

4. Microsoft / GitHub

工程團隊最完整的 Workflow 工具鏈

  • Plan Mode 主打「Strategy before code」，先產出藍圖計畫經人工審核 confirmation。
  • Agent Mode 取得授權後自行決定步驟、跨檔修改 Code、執行 Terminal 指令並驗證 Build/Test。
  • 開放生態 GitHub 現已支援將 Codex 或 Claude 當作第三方 Coding Agent 直接派發 Issue 任務。
團隊 AI 標準化落地建議

如何統一團隊的 AI 開發流程？

不要規範「全公司只能用 ChatGPT」或硬性規定 TASK 必須使用特定品牌。應該規範 AI Role（角色）與 Working Agreement（工作協定）。

Standardized Agent Workflows (角色導向工作流)

Step 1
Conversation AI
ChatGPT / Claude / Gemini / Copilot
產出：Requirements
Step 2
Work / Analysis AI
ChatGPT Work / Claude Cowork / Gemini
產出：docs/ & tasks/ & AGENTS.md
Step 3
Coding Agent
Codex / Claude Code / Gemini CLI / Copilot
執行：Plan → Code → Build / Test
Step 4
Human Review
工程師人工 Review Git Diff / PR
完成：Merge & Deploy

團隊應統一的「AI 工作協定」

要求不論使用哪一家 Coding Agent，都必須遵守專案根目錄下的： AGENTS.md、 coding conventions、 security rules 與 definition of done (DoD)。

任務指派寫法建議

錯誤寫法：「TASK-03 必須用 Codex 執行。」
正確寫法：「TASK-03 交由 Coding Agent 執行（任選 Codex / Claude Code / Copilot Agent Mode / Gemini CLI）。」
